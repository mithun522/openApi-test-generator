Generated tests

Paste a contract and select Generate test cases. Not sure where to start? Load the sample contract.
To run in Postman:
  1. Copy the collection JSON.
  2. In Postman choose Import, then Raw text, and paste it.
  3. Open the collection's Variables tab and fill in baseUrl and the auth values (token, apiKey, username/password). The Authorization tab already points at them.
  4. Run the collection with the Collection Runner to execute every test.
