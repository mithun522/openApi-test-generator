Generated tests

Paste a contract and select Generate test cases. Not sure where to start? Load the sample contract.
To run in Postman:
  1. Download the collection (or copy its JSON).
  2. In Postman choose Import, then drop in the downloaded file, or pick Raw text and paste the JSON.
  3. Open the collection's Variables tab and fill in the base URL and the auth values (by default baseUrl, token, apiKey, username/password; rename them under Postman variable names). The Authorization tab already points at them.
  4. Run the collection with the Collection Runner to execute every test.
